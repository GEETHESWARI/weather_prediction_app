# Weather Prediction App  


Description of the app:



**Weather Prediction App**

Our Weather Prediction App uses  machine learning techniques to forecast weather conditions accurately. By leveraging a dataset with input features such as precipitation, maximum and minimum temperature, and wind speed, we have built a robust model using the Random Forest algorithm.

**Key Features:**
- **Input Features:** Precipitation, Maximum and Minimum Temperature, Wind Speed
- **Algorithm:** Random Forest
- **Accuracy:** Achieved an accuracy of 81.59% in weather prediction
- **Data Analysis:** Conducted thorough data analysis with various visualization techniques such as wind and precipitation charts, and pair plots
